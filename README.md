# Hypixel QuestViewer

QuestViewer is a client-side Fabric (26.2+) & Forge (1.8.9) mod for Hypixel that lets you check active daily, weekly, and monthly quest progress directly in chat without visiting the Quest Master NPC.

---

## Features

* **Quest Tracking:** View daily, weekly, and monthly quest progress for the game you are playing, or search for other games and players.
* **Hotkey Support:** Press K for daily or J for weekly quests (configurable in controls) to check your progress in chat.
* **Completion Sounds:** Plays a chime when you complete a daily, weekly, or monthly quest.
* **Stats and Leaderboard:** View general Hypixel network stats, quest completion summaries, or the Top 100 overall completed quests leaderboard.
* **Sound Notifications:** Toggle quest completion sounds on or off.

---

## Commands

| Command | Shortcut | Description |
| :--- | :--- | :--- |
| `/q daily` | `/q d` | View daily quests for your current game |
| `/q weekly` | `/q w` | View weekly quests for your current game |
| `/q monthly` | `/q m` | View monthly quests for your current game |
| `/q daily [game] {ign}` | `/q d [game] {ign}` | View daily quests for a specific game or player |
| `/q weekly [game] {ign}` | `/q w [game] {ign}` | View weekly quests for a specific game or player |
| `/q monthly [game] {ign}` | `/q m [game] {ign}` | View monthly quests for a specific game or player |
| `/q summary` | `/q sum [ign]` | View quest completion summary |
| `/q leaderboard [1-10]` | `/q lb [page]` | View the Top 100 completed quests leaderboard |
| `/q stats` | `/q s [ign]` | View general Hypixel network stats |
| `/q games` | `/q g` | List supported game aliases |
| `/q notification toggle` | `/q n t` | Toggle quest completion sounds ON or OFF |
| `/q notification daily` | `/q n d` | Test daily quest completion sound |
| `/q notification weekly` | `/q n w` | Test weekly quest completion sound |
| `/q notification monthly` | `/q n m` | Test monthly quest completion sound |
| `/q site` | — | Get a link to the 25Karma quest page |
| `/q help` | `/q h` | Display the help menu |
